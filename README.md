# Deutsch mit Felix · web

Página de presentación de la app Android **Deutsch mit Felix A1 und A2** (Google Play: `com.deutschmitfelix.app`), en 8 idiomas.

Publicada en https://alvar56.github.io/deutsch-mit-felix/

- `index.html` se genera con `python montar.py` a partir de `plantilla.html`, `textos.json` (los textos de cada idioma) e `iconos.json`.
- El idioma sale del navegador; también `?lang=es|en|de|uk|tr|bks|ar|zh`.
